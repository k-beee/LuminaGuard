# LuminaGuard Frontend Console 🛡️

A modern, responsive Next.js 14 console built for the LuminaGuard intelligent fact adjudication protocol on GenLayer.

## Key Features

- **Decentralized Fact Adjudication:** Interacts directly with the LuminaGuard GenVM intelligent contract on StudioNet.
- **Dual Connection Engine:** Supports injected Web3 wallets (MetaMask) with automated StudioNet network switching (`61999`) and a built-in direct key signer.
- **Full Claim Lifecycle:** Declare inquiries, lock parameters, fund native escrow vaults, submit source materials, and ignite GenVM multi-validator consensus rounds.
- **Real-Time Verification:** Direct transaction inspection linked to the official GenLayer StudioNet Explorer.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build

```bash
npm run build
```
